                    Transparent Scientific Limitations
                    Scope & Constraints
                  

                  

                    

                      LIMITATION
                      

                        Integer Primary Keys: The Strawberry GraphQL schema strictly accepts and resolves integer IDs (e.g. id: 101). Non-integer slug or UUID lookups are outside current schema capability.
                      

                    

                    

                      LIMITATION
                      

                        Polymorphic Interfaces: GraphQL Union and Interface types (e.g. Node or SearchResult) are not defined in the current schema; single-inheritance concrete object types are evaluated.
                      

                    

                    

                      HONESTY
                      

                        Binary Decision Parity: On single-object queries, Method B (Gateway) and Method C (Correlated) achieve identical binary accuracy (89.3%). Method C's decisive advantage is AST Path Attribution (96.4% vs 0.0%) and static false-positive suppression.
